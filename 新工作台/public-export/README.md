# 公开网页版构建

公开站以浏览器内计算模式展示发布版本的档案。评估、情景、站点定位、流域气候、RSEI 对照和查询均复用生产构建与真实档案。生态评估和本地意图解析编译原服务的实现。公开智能体没有模型服务凭据，依照可重现的查询规则读取发布快照。修订和本地评估留痕使用桌面工作台的运行数据库。

## 导出

先启动最新本地版本。然后从工作台目录执行下列命令。

```powershell
npm.cmd ci
npm.cmd start
```

在另一个终端运行，指定一个空目录作为部署输出。

```powershell
npm.cmd run export:web -- --output (Join-Path $env:TEMP 'jinsha-pages')
```

脚本默认从 `http://127.0.0.1:8732` 读取只读公开数据。如用隔离端口，增加 `--origin http://127.0.0.1:8791`。输出包含 `index.html`、`.nojekyll`、静态资源、压缩数据与来源说明。把整个输出作为一个 Pages artifact 部署。根路径或仓库项目子路径均可用。公开包可在普通静态 HTTPS 服务运行，要求支持 ES 模块、WebGL2 与 Compression Streams API 的浏览器。使用 `file://` 打开时浏览器的跨文件访问限制会影响功能。

地图公开影像来自 NASA GIBS。地图模块与接口数据随部署一起提供，访客浏览时不需要连接本机、Ollama 或外部地图服务。公开包只导出脚本明确列出的公开数据，修订数据库和用户信息属于本机工作台运行资料。
