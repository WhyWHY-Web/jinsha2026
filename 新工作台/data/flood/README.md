# 金沙江历史日流量

`glofas-daily.json.gz` 收录 1997-01-01 至 2025-12-31 的 4 个河道网格模型日值，按 UTC 日期存放，共 10,592 天、42,368 条，单位为 m³/s。同名站点用于和现有项目台账对应，实际模型格点坐标以源响应为准。

| 对应站点 | 格点纬度 | 格点经度 |
|---|---:|---:|
| 石鼓 | 26.875 | 99.975006 |
| 攀枝花 | 26.575005 | 101.725006 |
| 屏山 | 28.625 | 104.17502 |
| 向家坝 | 28.675003 | 104.42502 |

数据来自 Copernicus GloFAS v4，经 Open-Meteo Flood API 获取。源字段包括日期、日流量、格点坐标和时间区。读取时验证日序列与单位，并校验各格点日期一致、数据连续且流量值有效。将 2020 年 8 月格点日值计算为月均和月内日峰，与原项目月档案对照至其保留精度。

回放按向家坝各年最大日流量排序选取 8 期，窗口为峰日前后各 10 日。P95 使用各格点自身全期日流量按最近秩法计算。地图站点色阶表示相对于该参考值的日流量，应用口径为历史模拟档案。
