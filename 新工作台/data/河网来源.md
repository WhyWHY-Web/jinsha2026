# 金沙江流域河网数据

以原项目的 27 个水文子流域裁剪 HydroRIVERS v1.0 亚洲河网。裁剪区面积约 475,261 km²，范围为东经 90.545570–104.942272°、北纬 24.474998–35.767283°。GeoJSON 坐标为 WGS84，经度在前。旧站点 DEM 仅覆盖东经 97.6–105.4°、北纬 25.9–32.5°。

| 文件 | 河段数 | 用途 |
| --- | ---: | --- |
| rivers.geojson | 27,524 | 分级专题、河段详情、完整区域分析 |
| rivers-major.geojson | 4,248 | Strahler 级别 ≥4，用于全流域概览 |
| river-mainstem.geojson | 1,003 | 顺序连通的模型主路径，用于独立干流描边 |
| rivers.source.json | | 字段说明、覆盖范围、来源与归档校验和 |

主路径从 HydroRIVERS 在宜宾附近的出流河段逆向追踪，每个汇流点选择上游累积集水面积较大的路径。该路径约 3,318.7 km，包含长江源区上游。平均流量是 HydroRIVERS 的多年模型估算，单位 m³/s。河段原始长度与裁剪区内计算长度分别保存，原始下游索引可能引用裁剪区外的河段。

## 原数据清点

原项目含 20 个站点、679 条 DEM 派生水系线和 45 条合成干支流水系。气候专题有 9,072 条月值和 756 条年值，水文专题有 1,392 条月值和 116 条年值。RSEI 归档覆盖八期。SQL 快照清单有 38 项、134,791 行，其中金沙江格点月值 84,240 行、遥感月值 31,240 行。快照对象之间存在重叠，行数表示归档条目总量。

## 复现

下载官方亚洲 Shapefile ZIP，安装 Python 3.11+、GeoPandas、Shapely 2、PyProj 和 Pyogrio，再在新工作台运行：

    python scripts/import_hydrorivers.py /path/to/HydroRIVERS_v10_as_shp.zip

默认读取相邻旧项目的流域 GeoJSON。脚本接受自定义输入路径和输出目录。
