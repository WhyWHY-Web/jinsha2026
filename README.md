# 金沙江生态研究工作台

当前唯一维护的产品是 `新工作台/`。同一套工作台可在网页中使用，也可由 Windows 便携软件启动。

- **网页运行**：在 `新工作台/` 构建并启动服务，浏览器访问 `http://127.0.0.1:8732/`。
- **Windows 软件**：完整解压 `dist/Jinsha-Workbench-Windows-x64-0.3.1.zip`，双击其中的启动程序。包内包含 Node.js 运行时与离线研究资料。
- **静态网页分发**：`新工作台/scripts/export_web.mjs` 导出同一产品的只读版本，可放到静态网站服务器。

```powershell
cd 新工作台
npm.cmd ci
npm.cmd run build
npm.cmd start
```

需要 Node.js 24。详细操作、数据条件、打包与导出命令见 [产品说明](新工作台/README.md)。

## 当前能力

生态评估、地图探索、数据与方法、成果中心四个主入口。生态评估内包含当前状态、两期变化、未来七天气象驱动、输入敏感性，以及同次运行的证据保存与导出。

EEI 沿用项目经验模型，无固定 100 分上限。站点均值不代表流域面积统计；未来页面提供气象驱动和研究核查线索，生态风险模型尚未校准，不提供灾害概率。模拟总览、查表情景、虚拟预案、示例视频及假动态告警已移除。

## 资料与目录

| 位置 | 用途 |
| --- | --- |
| `新工作台/` | React 前端、Node 后端、数据导入与交付工具 |
| `系统/data/` | 原始数据源；不要移动、重命名或覆盖 |
| `新工作台/data/` | 新增公开研究资料与地图背景 |
| `新工作台/data/live-data/` | 后台采集的运行快照，忽略提交 |
| `dist/` | 软件与网页交付产物，忽略提交 |
| `调研/` | 产品测评与改进方案 |

旧版 Python 源码已经归档，不再作为启动或发布入口。数据大文件的获取条件见 [数据获取说明](数据获取说明.md)。原始影像、切片、运行数据库及凭据不进入 Git。
