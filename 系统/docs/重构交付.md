# 金沙江生态数字孪生重构交付

## 设计与使用

系统以本地三维地图为默认入口。态势总览用于查看流域和分段结论，智能评估和生态评估用于查看各项指标，风险预警与巡检用于定位重点站点并进入区域治理。贫困–生态耦合协调专题可切换年份、比较空间分布、查看站点结果及分析口径。

左栏显示流域摘要、年度趋势和优先核查站点。地图清单、风险分布图及巡检建议可定位站点，右栏随之切换到该站的评估。底部时间轴共用年度状态，驱动 NDVI 站点着色和气候读数。图层抽屉可检索站点、筛选风险、切换底图、调整叠加图层的顺序和透明度。

地形使用本地 DEM 和卫星镶嵌影像。干流按本地河网几何绘制，使用定向脉冲和高亮阈值泛光。剖面由干流中心线和 DEM 计算。情景模拟对土地覆盖份额重新分配后复用原评估公式。退化管理按各站林地的 15% 转为裸地，生态修复按各站裸地的 25% 转为林地。这两项是本次采用的情景参数，可在界面读取。

## 产品调研与采用方式

- 超图水利数字孪生和 Cesium 提供了共用地形底板和独立图层的参考。本系统在一块地图上切换流域、河段与站点视角。 [超图](https://cn.supermap.com/zh-cn/a/case/49_4072.html) · [Cesium](https://cesium.com/learn/cesiumjs-learn/cesiumjs-terrain/)
- NASA Worldview 和 kepler.gl 的日期选择与播放用于设计底部时间轴。Copernicus Browser 的地点统计用于设计选站后的时序分析。 [NASA Worldview](https://worldview.earthdata.nasa.gov/) · [kepler.gl](https://docs.kepler.gl/docs/user-guides/h-playback) · [Copernicus Browser](https://documentation.dataspace.copernicus.eu/Applications/Browser.html)
- ArcGIS Dashboards、USGS 和 Forest Watcher 提供了清单定位、站点详情与核查衔接的参考。 [ArcGIS Dashboards](https://doc.arcgis.com/en/dashboards/latest/create-and-share/actions.htm) · [USGS Water Data](https://www.usgs.gov/tools/water-data-nation-wdfn) · [Forest Watcher](https://fw.globalforestwatch.org/)
- 阿里云 AI Earth 的成果分层和数据检索用于设计图层与数据状态入口。调研也纳入了国内灌溉和流域数字孪生案例。 [阿里云 AI Earth](https://www.aliyun.com/product/ai/rsimganalys) · [ThingJS-X](https://x.thingjs.com/case/yd.html) · [广东北江与韩江](https://www.shanwei.gov.cn/swsswj/gkmlpt/content/1/1166/post_1166310.html)

## 数据、接口与科学口径

- FastAPI 提供同源页面和业务 API。运行时 SQLite 从原始 JSON 幂等初始化，区域治理、站点修正、情景、任务、账号和审计由本地服务管理。原始影像、DEM、瓦片和归档数据可在离线包读取。
- `eco_metrics.py` 保存评估公式，`server.py` 在计算前解析治理有效值，`state_store.py` 管理 SQLite，`api_schemas.py` 定义智能体接口结构。旧版调用入口通过同源路由兼容。
- RSEI 展示现有 1990–2025 年八期归档均值及可用的空间样本。GCPI、LTCCD 的站点示范使用 2015、2020、2025 年数据，并在页面列出灯光、人口密度和可达性的代理口径。各站的本地、远程耦合使用 IDW，远程输入的权重按接收站归一化。趋势面板显示 Sen、Mann–Kendall、Moran’s I 和 Theil 指标。
- 本地智能体用数据接口返回结论、依据、建议和置信说明，提供站点定位与区域复核。可选在线模型通过设置接入。内置模型训练使用现有站点评估标签。SWAT、InVEST 等外部引擎的条目用于展示研究路线，运行这些完整模型依赖各自的参数、输入和校准数据。
- 当前仓库提供 DEM、卫星影像、GEE 时序与专题归档。无人机多光谱和其他未取得的实测输入属于后续数据采集。地形与气候保持各自来源和尺度。

## 启动与构建

双击单文件程序可启动本地服务并自动登录。浏览器地址以启动窗口显示的端口为准。手动登录使用原账号或首次启动生成的本地账号密码。

在源码目录内可使用以下命令。Swagger 位于运行中地址的 `/docs`，在线气候同步需显式设置 `JINSHA_ONLINE=1`。

```powershell
python -m pip install -r requirements.txt
python boot.py
python build_dist.py --full
```

源码与打包运行分别使用独立的本地状态目录。测试可设置 `JINSHA_STATE` 指向临时目录。
