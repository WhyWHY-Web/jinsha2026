## 二、源程序材料（最容易出错的地方）

**规则**：提交前 30 页 + 后 30 页，共 **60 页**；每页 **不少于 50 行**（不足会有风险）；页眉写**软件全称 + 版本号**；页脚连续页码；删除空行与纯注释行，但保留必要注释。

操作步骤：

1. 统计总行数：
   ```bash
   cd 系统
   cat server.py launcher.py main.py tools/*.py web/app.html web/login.html \
       web/assets/*.js | grep -v '^\s*$' | wc -l
   ```
2. 生成 60 页文档：每页 50 行 → 需要 3000 行，从前 1500 行、后 1500 行各取。
   - 顺序建议：`launcher.py → server.py（核心）→ web/assets/region.js → web/app.html（节选）`
   - **不要**把 `node_modules`、`vendor/three.min.js`（第三方库）、`data/*.json` 放进源码材料
3. 页眉示例（Word 页眉居中，小五号宋体）：
   ```
   金沙江流域森林生态环境智能评估系统 V1.0
   ```
4. 导出 PDF，检查：共 60 页、每页行数 ≥ 50、页眉每页都有、无乱码（中文用 UTF-8 打开）。

## 六、最容易被打回的 5 个原因

1. 页眉缺版本号，或与申请表名称不一致（差一个“系统”两个字都不行）。
2. 源码不足 60 页却按 60 页排版（总行数 < 3000 行时全部提交，并在说明里注明“全部源码”）。
3. 每页行数不足 50（删空行删过头）。
4. 说明书没有截图，或截图与功能描述对不上。
5. 软件名称含“中国”“国家”等字样，或暗示政府背景。
