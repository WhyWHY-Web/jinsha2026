# 绑定自己的域名（jinsha2026why.com）操作指南

> 现状：免费的临时隧道（trycloudflare / loca.lt / serveo）**都无法给一个固定且干净的
> `jinsha2026why.xxx`**——要么地址每次变，要么带浏览器警告页。想要“自己的域名”，
> 需要先拥有一个域名（约 10–30 元/年），再用 Cloudflare 免费套餐把它指到本机。

---

## 一、买域名（5 分钟）

任选一家，买 `jinsha2026why` 这个前缀：

| 平台 | 推荐后缀 | 首年参考价 |
|---|---|---|
| 阿里云万网 | `.top` / `.xyz` / `.com` | 10–70 元 |
| 腾讯云 DNSPod | `.top` / `.cn` | 10–30 元 |
| NameSilo（海外，免备案） | `.com` | ≈ 70 元 |

> 只做展示、不解析到国内服务器，**不需要备案**；用 Cloudflare 代理即可。

---

## 二、把域名托管到 Cloudflare（免费，10 分钟）

1. 注册 <https://dash.cloudflare.com>（免费计划）
2. Add a site → 输入 `jinsha2026why.com` → 选 Free
3. Cloudflare 会给两个 NS 地址，回到购买平台把域名的 DNS 服务器改成这两个
4. 等 10 分钟–2 小时生效（Cloudflare 面板显示 Active）

---

## 三、建立命名隧道（一次性，5 分钟）

在项目目录执行（`cloudflared.exe` 已在 `tools/bin/`）：

```bat
tools\bin\cloudflared.exe tunnel login
tools\bin\cloudflared.exe tunnel create jinsha
tools\bin\cloudflared.exe tunnel route dns jinsha jinsha2026why.com
tools\bin\cloudflared.exe tunnel route dns jinsha www.jinsha2026why.com
```

第一条会弹浏览器让你选刚才那个域名；第二条会生成一个隧道 ID 和证书
（在 `C:\Users\<你>\.cloudflared\` 下）。

把生成的隧道 ID 填进 `tools/named-tunnel.yml` 的 `tunnel:` 字段。

---

## 四、启动

```bat
tools\bin\cloudflared.exe tunnel --config tools\named-tunnel.yml run
```

之后 `https://jinsha2026why.com` 就是你的固定地址，重启电脑也不变。
需要开机自启时，把上面这行做成计划任务即可（或用 `nssm` 注册为服务）。

---
